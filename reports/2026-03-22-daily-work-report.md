### 动态定价策略 (04:10)

**定价因子**:
- 供需关系：实时供需比、预测偏差
- 时段因素：高峰/平峰/低谷
- 场景因素：天气、事件、节假日
- 用户画像：价格敏感度、出行目的

**算法模型**:
```
最终价格 = 基础价格 × 供需系数 × 时段系数 × 个性化系数
```

**OTA 差异化**:
- 航班动态联动：延误/取消自动触发运力调度
- 企业差旅协议价 + 动态浮动

---

### 司机运营管理 (04:15)

**运力管理核心**:
- 需求预测：时空粒度预测 (15 分钟/1km 网格)
- 调度算法：全局最优 vs 局部最优权衡
- 司机激励：冲单奖、热力图引导、动态分成

**供给侧优化**:
- 全职司机：稳定性保障 + 福利体系
- 兼职司机：灵活激励 + 峰值补充
- 预约单：提前锁定运力

### 需求分析与 PRD (04:30)

**需求挖掘五步法**:
1. 问题定义：用户痛点是什么
2. 用户研究：定性访谈 + 定量数据
3. 需求转化：用户语言 → 产品语言
4. 优先级评估：RICE 评分框架
5. PRD 输出：可执行文档

**PRD 核心结构**:
- 背景与目标
- 用户故事与场景
- 功能需求详述
- 数据埋点设计
- 验收标准

---

### A/B 测试实验 (04:35)

**实验设计原则**:
- 单一变量：每次只测试一个因素
- 样本量充足：统计显著性保证
- 随机分组：避免选择偏差
- 周期合理：覆盖完整用户行为周期

**分析框架**:
- 核心指标：转化率、留存率、GMV
- 辅助指标：点击率、停留时长、跳出率
- 显著性检验：p-value < 0.05

---

### OKR 目标管理 (04:40)

**OKR 设计原则**:
- O (目标): 鼓舞人心、方向明确、有挑战性
- KR (关键结果): 可量化、可验证、有截止时间

**示例**:
```
O: 打造行业领先的接送机体验
KR1: 接送机订单转化率提升至 35% (当前 28%)
KR2: NPS 评分提升至 60+ (当前 45)
KR3: 司机准时率提升至 95% (当前 88%)
```
