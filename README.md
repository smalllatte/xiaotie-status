## 📁 数据结构

### API 端点
`/api/status.json` - 返回实时状态数据

### 数据字段
- `timestamp` - 数据时间戳
- `version` - 版本号
- `status.workspace` - 工作区状态（工作中/空闲中）
- `status.learning` - 学习区状态（学习中/空闲中）
- `currentSession` - 当前任务信息
- `today.tasks` - 今日任务数
- `today.messages` - 消息交互数
- `today.learning` - 学习条目数
- `today.uptime` - 在线时长（秒）
- `today.uptimePercent` - 在线率（%）
- `learning[]` - 学习进度数组（含笔记数量和主题）
- `activities[]` - 活动日志（按时间倒序）
- `meta` - 元数据（总笔记数、数据来源等）
